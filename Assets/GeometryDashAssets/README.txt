Geometry Dash-Style Godot Asset Pack

Folders:
- Player: cube sprite sheet / animation frames
- Tiles: platform and ground tile sheet
- Hazards: spikes, saws, hanging hazards
- Enemies: enemy sprite sheet
- PowerUps: shield, coin, gem, heart, star, orb
- Finish: portal / finish-line assets
- UI: menu buttons and icons
- Backgrounds: parallax mountain/background layers
- Reference: full visual reference sheet

Recommended Godot import location:
res://Art/

These PNG files are sprite sheets. In Godot, use regions / AtlasTexture / SpriteFrames to select the individual asset you want from each sheet.
